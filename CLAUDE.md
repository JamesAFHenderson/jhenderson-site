# Project: jhenderson.uk

One-page consultancy site for James Henderson — fractional Head of Sales 
and UK market entry advisor for beverage brands.

## Stack
- Plain HTML, CSS, JavaScript. No frameworks.
- Tailwind CSS via CDN (Play CDN for dev, will swap for production build later).
- Single `index.html` file. Inline styles only where Tailwind can't reach.

## Design principles
- Editorial, not corporate. Think Monocle / Drift / less is more.
- One serif display font + one clean sans (Google Fonts).
- Generous whitespace. Strong typographic hierarchy. Black/white + one accent.
- Must look credible to a £5m+ beverage brand founder on a desktop AND phone.

## Don't
- Don't add frameworks, build tools, package.json, or npm dependencies.
- Don't use stock-photo people. Logos/wordmarks of brands worked with only.
- Don't write fluffy marketing copy. Concrete numbers, specific accounts.

## Deploy
- GitHub repo → Vercel → custom domain jhenderson.uk.
